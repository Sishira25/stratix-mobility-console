# Stratix | Enterprise Mobility & GTM Intelligence Console

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://stratix-mobility-console.streamlit.app/)

**Stratix** is a high-performance, production-ready web application built for B2B enterprise sales teams, account executives, and sales operations. It automates the heavy lifting of enterprise account research—calculating mobile device density, auditing IT infrastructure, and generating tailored go-to-market (GTM) strategies and executive sales pitches in seconds.

---

## Key Features

* **Account Intelligence & Instant Lookup:** Search or select from a robust database of enterprise accounts across multiple industries. Dynamically calculates estimated corporate mobile device fleets using industry-specific density ratios.
* **Automated GTM Strategy Matching:** Analyzes an enterprise's current MDM integrations (e.g., Microsoft Intune, Jamf, MobileIron) and hardware lock-in status to recommend optimal commercial frameworks (such as Buy-and-Rent-Back / BARB or standard DaaS).
* **Dynamic Pitch Generation:** Instantly crafts personalized, professional B2B cold outreach emails tailored to the target company's precise scale and infrastructure.
* **CRM Batch Ingestion & Pipeline Management:** Features a built-in file uploader for Salesforce/HubSpot CSV/Excel exports, a searchable live database table, and an account appender form.
* **Enterprise Trust & Compliance View:** Outlines core security standards like ISO 27001, GDPR, NIS-2 compliance, and Blancco secure data erasure audit trails.

---

## Tech Stack

* **Frontend & Framework:** Python, Streamlit
* **Data Processing & State Management:** Pandas, Streamlit Session State
* **Styling:** Custom CSS Injection (Trust Blue & Slate Enterprise Palette)
